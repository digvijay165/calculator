# Calcu

A clean, responsive calculator that runs in your browser. It includes everyday arithmetic and a set of scientific tools, with no installation or build step required.

**Live calculator:** [calculator-7rgb.onrender.com](https://calculator-7rgb.onrender.com)

## Features

- Basic arithmetic and expression entry
- Scientific functions: trigonometry and inverse trigonometry, square root, logarithms, absolute value, exponentials, and factorials
- Degree and radian angle modes
- Constants for pi and e
- Memory controls: MC, MR, M+, and M−
- Calculation history saved in the browser, with up to 40 recent calculations
- Light and dark themes
- Keyboard input and a layout that adapts to smaller screens

## Use it

Open the [live calculator](https://calculator-7rgb.onrender.com), or open `index.html` in a browser to run it locally. Select **Scientific** to show the scientific functions and use **DEG/RAD** to change the angle mode.

Press **Enter** to calculate and **Escape** to clear the current entry. Use the History button to revisit a recent calculation.

## Built with

Plain HTML, CSS, and JavaScript. The app has no package dependencies or build command.
